Instalar o agente

O agente lê CPU, RAM, disco, S.O., vídeo, tempo ligada e localização, e envia cifrado ao sistema a cada 30 min. Instale uma vez em cada computador.

Windows (.zip) Linux Mint (.zip)

Windows

Baixe o Windows (.zip) → extraia tudo → Win+R → shell:startup → cole os arquivos → 2 cliques em iniciar_agente.vbs. Não aparece janela: é normal.

Ver passo a passo detalhado
  1. Clique no botão Windows (.zip) aqui em cima. O arquivo cai na pasta Downloads.
  2. Abra a pasta Downloads e ache o arquivo terminado em .zip.
  3. Antes de abrir: botão direito no .zip → Propriedades. Se houver “Desbloquear” lá embaixo, marque → OK. (Se não tiver, siga.)
  4. Botão direito no .zip → Extrair Tudo… → Extrair. Abre uma pasta com vários arquivos.
  5. Dentro dela: Ctrl+A (selecionar tudo) e Ctrl+C (copiar).
  6. Segure a tecla Windows (a do logo) e aperte R → digite shell:startup → Enter.
  7. Clique na pasta que abriu e aperte Ctrl+V (colar).
  8. Dê dois cliques em iniciar_agente.vbs. Não aparece nada na tela — é normal, já enviou.

Não aparece na lista, ou conta limitada? Botão direito em instalar_tarefa.bat → Executar como administrador. Conferir: dois cliques em diagnostico.bat.

Linux Mint / Ubuntu

Baixe o Linux Mint (.zip) → extraia → abra o Terminal na pasta → digite bash instalar.sh e Enter. Agenda sozinho, sem root.

Ver passo a passo detalhado
  1. Clique no botão Linux Mint (.zip) aqui em cima. O arquivo cai em Transferências.
  2. Abra o gerenciador de arquivos (ícone de pasta amarela) e entre em Transferências.
  3. Botão direito no .zip → Extrair aqui. Entre na pasta criada (dois cliques).
  4. Botão direito num espaço vazio dentro da pasta → “Abrir no Terminal” (janelinha preta).
    Não achou? Abra o Menu, digite Terminal, e depois cd até a pasta.
  5. Digite bash instalar.sh e aperte Enter (colar = Ctrl+Shift+V).
  6. Espere a mensagem de sucesso. Pronto. Roda sozinho a cada 30 min, sem root.

Conferir: no Terminal, na mesma pasta, rode bash coletar_score.sh --diag.
